## RPA & Automation

### [Enterprise Invoice Processing Automation with UiPath Orchestrator](rpa/uipath.md)
<small>An end-to-end RPA solution that automates vendor invoice processing — from Gmail retrieval to a consolidated Excel tracking report — built with UiPath and deployed through UiPath Orchestrator.</small>

### [Vendor Invoice Management Portal](rpa/vendor.md)
<small>A cloud-based Vendor Invoice Management Portal that enables vendors to submit multiple invoice records through a responsive web interface. The application stores structured invoice batches in MongoDB Atlas and sends a JSON representation of each submission through Gmail for downstream processing and future RPA integration.</small>

## DevOps & Infrastructure

### [Local DevOps HomeLab with Docker, Kubernetes & Ansible](devops/localdevops.md)
<small>A local DevOps homelab that provisions and configures multi-host infrastructure using **Vagrant** and **Ansible**, deploying a containerized web server (Nginx via Docker) and a database server (MariaDB) without relying on any cloud provider.</small>

## Other Projects

### [Associated with PT Bank Central Asia Tbk](others/bca.md)
<small>A record of enterprise batch operations, configuration management, and infrastructure projects delivered for PT Bank Central Asia Tbk (BCA). These engagements center on Control-M batch scheduling infrastructure, supported by Spring Boot (Java) services and Python tooling, across configuration management, service automation, infrastructure migration, disaster recovery, regulatory compliance, and large-scale agent upgrades.</small>

### [Technical Documentation Setup with MkDocs — Salma's Tech Journey](others/mkdocs.md)
<small>A demonstration of technical writing and documentation-system design: building and structuring **Salma's Tech Journey**, a professional portfolio site, using MkDocs and the Material theme — covering site architecture, content standardization, and authoring workflow.
</small>
