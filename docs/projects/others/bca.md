# Projects Associated with PT Bank Central Asia Tbk

A record of enterprise batch operations, configuration management, and infrastructure projects delivered for **PT Bank Central Asia Tbk (BCA)**. These engagements center on Control-M batch scheduling infrastructure, supported by Spring Boot (Java) services and Python tooling, across configuration management, service automation, infrastructure migration, disaster recovery, regulatory compliance, and large-scale agent upgrades.

## Centralized Configuration Optimization for 700+ Jobs

**Period:** Jan 2021 – Feb 2021
**Skills:** Configuration Management

Implemented a Centralized Connection Profile (CCP) for over 700 Plugin and API jobs, eliminating redundant per-agent configurations.

**Outcomes**

- Removed duplicated configuration across agents
- Improved long-term maintainability of job definitions
- Reduced manual configuration effort
- Increased overall operational efficiency

---

## Service Automation & Request Workflow Standardization

**Period:** Jan 2022 – Sep 2022
**Skills:** Technical Documentation, Communication

Developed standardized service request procedures and documentation for Batch agent installation/uninstallation and job scheduling workflows.

**Outcomes**

- Improved internal process efficiency
- Simplified request handling across multiple teams
- Established repeatable, documented workflows for common batch operations requests

---

## Batch Application Infrastructure Migration & OS Upgrade

**Period:** Apr 2024 – Oct 2024
**Skills:** Server Migration, Unix

Supported multiple infrastructure migration initiatives, including Batch Process Application environment migration (Production & Development), OS upgrades, and a Tandem system transition.

**Outcomes**

- Migrated Batch Process Application environments across Production and Development
- Completed OS upgrades with minimal disruption
- Delivered the Tandem system transition successfully within timeline

## Disaster Recovery Simulation for Internal Application

**Period:** Apr 2025 – Apr 2025
**Skills:** Disaster Recovery, High Availability (HA)

Executed Disaster Recovery (DR) exercises for Internal Application and Database environments, including failover validation using RSYNC data replication.

**Outcomes**

- Validated failover procedures for critical services
- Confirmed system readiness and high availability posture
- Minimized downtime risk through tested DR procedures

## Batch Application Setup for Infrastructure Segregation (Regulatory Compliance)

**Period:** Apr 2025 – Nov 2025
**Skills:** System Setup, System Architecture

Prepared and implemented a new environment for subsidiary companies to support infrastructure segregation requirements in compliance with OJK regulations.

**Outcomes**

- Ensured proper environment isolation between entities
- Delivered system readiness for the segregated environment
- Achieved seamless integration with existing infrastructure while maintaining operational stability

## Agent Mass Upgrade (2000+ Production & Development Nodes)

**Period:** Jan 2025 – Apr 2026
**Skills:** Linux, Windows Server

Led and supported the large-scale upgrade of more than 2,000 Batch Processing Agents across production and development environments.

**Outcomes**

- Upgraded 2,000+ agents across Linux and Windows Server environments
- Ensured smooth deployment with minimal downtime in a critical banking system
- Coordinated rollout across both production and development nodes
